# Security Policy

## Supported Versions

The project currently supports the latest development branch and the most recent release.

## Reporting a Vulnerability

Please report security issues privately through GitHub Security Advisories or by emailing security@smartbusiness.local.

Provide the following information in your report:

- affected component or endpoint
- severity assessment if known
- reproduction steps or proof of concept
- potential impact
- suggested remediation steps

Do not disclose vulnerability details publicly until a fix has been reviewed and released.
